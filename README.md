# ДЗ 1. Байесовский генератор стилей и аватаров

## Задача

Реализована первая часть ДЗ по курсу `DeepGen`:

1. Генератор стилей на основе категориальных признаков из `styles.py`.
2. Генератор аватаров на основе попиксельных распределений по набору готовых изображений.

Оба генератора возвращают не только результат генерации, но и вероятность его получения:

- по MLE;
- по байесовской оценке.

## Датасет и исходные данные

В качестве исходных данных использованы материалы из задания:

- `hw_1/styles.py` содержит 5 категорий признаков и частоты встречаемости значений;
- `hw_1/avatars/` содержит 11 PNG-аватаров размером `528x560`;
- исходный источник: `https://github.com/Skyfallk/2026_DeepGen_ITMO_course/tree/main/HW_1.Bias_gen_and_autoencoders`

При загрузке аватаров используются исходные `RGBA`-изображения. Прозрачность моделируется отдельно, а итоговые изображения сохраняются на белом фоне.

## Реализация

- `hw_1/src/style_generator.py`:
  - использует частоты из `styles_count`;
  - интерпретирует каждую категорию как дискретную случайную величину с категориальным распределением;
  - считает MLE-оценки вероятностей по относительным частотам;
  - считает байесовские вероятности как posterior predictive распределение Дирихле;
  - генерирует случайный стиль и возвращает его вероятность.

- `hw_1/src/avatar_generator.py`:
  - загружает набор аватаров;
  - отдельно моделирует вероятность непрозрачности каждого пикселя;
  - для каждого пикселя и каждого канала `R`, `G`, `B` оценивает дискретные распределения по наблюдаемым значениям;
  - считает MLE-оценки по локальным частотам;
  - строит байесовские вероятности через posterior predictive с глобальными априорами по каналам;
  - генерирует цвет пикселя из множества наблюдавшихся в этой позиции `RGB`-значений с весами, полученными из поканальных вероятностей;
  - считает MLE- и байесовскую вероятности полученного изображения.

- `hw_1/src/generate_examples.py`:
  - генерирует 5 примеров стилей;
  - генерирует 5 примеров аватаров;
  - сохраняет артефакты в `hw_1/generated/`.

Логика реализации согласована с идеями из лекционного ноутбука по генеративному моделированию:

- категориальная часть строится как дискретная вероятностная модель по частотам;
- пиксельная часть рассматривается как baseline-генератор в предположении попиксельной вероятностной модели;
- вероятности для изображений считаются в логарифмической форме, так как прямое произведение большого числа малых вероятностей быстро приводит к потере точности.

## Результаты

Сгенерированные артефакты лежат в `hw_1/generated/`:

- `styles.json` — 5 сэмплов стилей с вероятностями;
- `avatars.json` — 5 сгенерированных аватаров с вероятностями;
- `report.md` — краткая сводка результатов;
- `avatar_1.png` ... `avatar_5.png` — сгенерированные изображения.

Примеры сгенерированных стилей:

- `Style 1`: короткая прическа, рыжие волосы, солнцезащитные очки, футболка с круглым вырезом, синяя одежда, байесовская вероятность `4.402679e-4`
- `Style 2`: короткая курчавая прическа, серебристо-серые волосы, солнцезащитные очки, худи, зеленая одежда, байесовская вероятность `4.891865e-4`
- `Style 3`: длинные прямые волосы, серебристо-серые волосы, круглые очки, футболка с круглым вырезом, зеленая одежда, байесовская вероятность `4.688038e-3`
- `Style 4`: длинные прямые волосы, серебристо-серые волосы, без очков, футболка с круглым вырезом, розовая одежда, байесовская вероятность `2.445933e-3`
- `Style 5`: короткая прямая прическа, пастельно-розовые волосы, солнцезащитные очки, футболка с V-вырезом, красная одежда, байесовская вероятность `9.131482e-5`

Для аватаров вероятности получаются экстремально малыми из-за произведения вероятностей по всем пикселям и каналам, поэтому они сохранены в научной записи и в логарифмической форме в `avatars.json`.

## Ограничения модели

Для стилевого генератора категориальная постановка работает ожидаемо, так как число состояний конечно и структура данных явно задана в `styles.py`.

Для пиксельного генератора качество ограничено самой наивной постановкой задачи:

- модель рассматривает значения пикселей и каналов как локальные дискретные признаки;
- пространственные зависимости между соседними пикселями явно не моделируются;
- из-за этого итоговые изображения могут быть визуально менее естественными, чем исходные аватары.

Это согласуется с обсуждением в лекционном ноутбуке: попиксельная наивная байесовская модель является рабочим baseline-подходом, но плохо учитывает сильную взаимозависимость признаков изображения.

## Дополнительные технические решения

Ниже перечислены дополнительные решения, которые использованы поверх базовой постановки:

- Прозрачность исходных `RGBA`-аватаров моделируется отдельно от цветовых каналов.
- Для байесовской части пиксельной модели используются глобальные априоры по каналам `R`, `G`, `B`.
- Цвет пикселя выбирается не из произвольной комбинации каналов, а из реально наблюдавшихся в этой позиции `RGB`-значений.
- Вероятности изображений сохраняются не только в обычном виде, но и в логарифмической форме.
- Для визуализации итоговых PNG применяется детерминированная медианная фильтрация `5x5`.

В `avatars.json` постобработка отмечена полем `visual_postprocess`, а сами вероятности относятся к вероятностной модели до визуальной постобработки.

## Запуск

```bash
uv sync
uv run python -m hw_1.src.generate_examples --count 5 --seed 42
```
