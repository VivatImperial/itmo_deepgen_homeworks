# Часть 1. Байесовский генератор стилей и аватаров

## Что сделано

В первой части реализованы два генератора:

- генератор стилей по категориальным признакам из `styles.py`;
- генератор аватаров по набору готовых изображений из `avatars/`.

Оба генератора возвращают результат и его вероятность в двух вариантах: по `MLE` и по байесовской оценке.

## Структура

- `styles.py` - исходные частоты категорий для генератора стилей;
- `avatars/` - исходные изображения аватаров;
- `src/style_generator.py` - генерация стиля;
- `src/avatar_generator.py` - генерация аватара;
- `src/generate_examples.py` - запуск и сохранение примеров;
- `generated/` - результаты генерации.

## Данные

Использованы материалы из задания:

- `styles.py` с частотами признаков;
- `11` исходных аватаров в формате `PNG`;
- источник: `HW_1.Bias_gen_and_autoencoders` из репозитория курса.

Для аватаров исходные `RGBA`-изображения приводятся к единому виду, прозрачность обрабатывается отдельно.

## Как устроено решение

Генератор стилей работает как дискретная вероятностная модель по категориям. Для каждого признака считаются вероятности по относительным частотам и байесовская оценка через апостериорное предиктивное распределение.

Генератор аватаров строит попиксельные распределения по исходному набору изображений. Прозрачность моделируется отдельно, а цвет пикселя выбирается из реально наблюдавшихся в этой позиции `RGB`-значений.

## Результат

Скрипт `src/generate_examples.py` формирует:

- `5` примеров стилей;
- `5` примеров аватаров;
- файл `generated/styles.json` со стилями и вероятностями;
- файл `generated/avatars.json` с метаданными и вероятностями;
- краткую сводку в `generated/report.md`.

Для аватаров итоговые вероятности очень малы, поэтому они сохраняются в научной записи.

## Запуск

```bash
uv sync
uv run python -m hw_1.task_1.src.generate_examples --count 5 --seed 42
```
